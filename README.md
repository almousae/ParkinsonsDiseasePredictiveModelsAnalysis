# Parkinson's Disease Predictive Models Analysis
## Description
Implemented machine learning models to predict Parkinson's Disease and identify significant risk factors 

## Data
Data accessible at https://www.ppmi-info.org/access-data-specimens/download-data

## Details
Analyzed a longitudinal Parkinson’s Disease dataset and examined multi-visit clinical, biomarker, and motor/mental health assessment data to study long-term disease progression

Integrated multimodal features from participants’ motor, psychological, neurological, pharmacological, verbal/linguistic, and physical assessments to characterize progression and identify early predictive risk factors

Ran decision trees and random forest models in parallel to maximize efficiency and reduce training time
